# 嵌入式工程师用什么 SSH 终端？聊聊我为什么自己做了一个

做嵌入式开发，SSH 终端是每天都要打开的工具。市面上选择不少，但每个都有让人难受的地方。先聊聊主流的几款。

## 市面上的 SSH 终端

**PuTTY** — 老牌经典，轻量免费。但 UI 停留在 Windows XP 时代，不支持多标签，不支持分屏，每次连一台新设备就多一个窗口。文件传输要单独开 PSCP 或 WinSCP，来回切换很烦。适合偶尔连一下服务器的人，天天用的话效率太低。

【截图：PuTTY 界面，可选】

**Xshell** — 功能全面，多标签，界面也不错。但个人免费版限制只能开 4 个标签，商业版要付费。对于嵌入式开发者来说，经常同时连好几台板子，4 个标签根本不够。而且 Xshell 和 Xftp 是两个独立软件，文件传输还是要切来切去。

**FinalShell** — 国产免费，SSH + SFTP 一体化，还有系统监控。很多嵌入式工程师在用。但问题也明显：Java 写的，内存占用大，界面卡顿是常态。免费版有广告，高级功能要付费。最让人头疼的是偶尔会莫名其妙断连，而且没有自动重连。

**MobaXterm** — 功能最丰富，SSH/SFTP/串口/X11 都有。但免费版限制 12 个会话，界面信息密度太高，功能堆砌感强。对于只需要 SSH + SFTP 的场景，太重了。

**Tabby (Terminus)** — 开源，颜值高，跨平台。但它更偏向本地终端，SSH 连接管理不够方便，SFTP 功能缺失，嵌入式场景下不太够用。

**WindTerm** — 开源免费，性能不错。但项目更新不太活跃，UI 风格偏传统，SFTP 集成度一般。

总结下来，嵌入式工程师对 SSH 终端的核心需求其实很简单：

1. 多标签 + 分屏，同时操作多台设备
2. SFTP 集成在同一个界面里，不要来回切换
3. 文件传输要快，经常要传几十 MB 的固件
4. 断线自动重连，嵌入式设备网络不稳定是常态
5. 界面干净，不要广告和多余的东西

但没有一款完全满足。所以我做了 XenoTerm。

## XenoTerm 的 SSH + SFTP

### 多标签 + 分屏

支持多标签，每个标签可以拖拽分屏。同时看两台设备的日志，左边跑程序右边看输出，不用在窗口之间切来切去。

【截图：多标签 + 左右分屏，两个终端同时显示】

### SFTP 一体化

点一下文件浏览器按钮，当前 SSH 会话直接打开 SFTP 面板。左边本地文件，右边远端文件，拖拽就能传。不需要单独开一个 SFTP 软件，不需要重新输密码。

【截图：终端下方的 SFTP 双栏面板，左本地右远端】

### 传输速度

底层用了 ssh2 的 fastGet/fastPut 并发传输，日常传固件、拉日志都很流畅。传输进度实时显示在浮窗里，不遮挡文件列表。传完自动刷新目录，不用手动点刷新。

【截图：传输进度浮窗，显示速度和进度条】

### 文件右键操作

远端文件支持右键菜单：重命名、删除、新建文件夹、修改权限。本地文件右键可以在资源管理器中打开或复制路径。不用为了改个文件名去终端里敲 mv 命令。

【截图：远端文件右键菜单】

### 断线重连

SSH 连接断开后，点一下重连按钮就能恢复会话。支持保存密码，重连时不用重新输入。嵌入式设备经常重启或网络波动，这个功能用过就离不开。

### 跳板机支持

连接配置里可以指定跳板机，XenoTerm 自动通过跳板机转发连接到目标设备。在公司内网通过堡垒机连开发板的场景很常见。

【截图：连接配置表单，显示跳板机选项】

### 密钥认证

支持密码和公钥两种认证方式。选择私钥文件，填入 passphrase（如果有的话），跟 Xshell 的体验一样。

### 命令历史

跨会话的命令历史记录，支持搜索和按主机过滤。上次在 A 板子上敲的命令，下次连 B 板子时也能找到。

【截图：命令历史面板，搜索和主机过滤】

### 连接管理

侧边栏管理所有连接，支持分组。双击直接连接，右键编辑或删除。连接配置支持导入导出 JSON，换电脑时不用重新配。

【截图：侧边栏连接列表，分组显示】

## 暗色主题 + 中英文

默认暗色主题，长时间使用不刺眼。支持中英文切换，界面紧凑不浪费空间。终端字体、字号、配色方案都可以自定义。

【截图：暗色主题整体界面】

【截图：亮色主题整体界面】

## 不止于 SSH

XenoTerm 定位是嵌入式通用调试工作站，除了 SSH/SFTP，还集成了串口调试、网络调试 (TCP/UDP)、CAN 总线、EtherCAT 等功能。一个软件覆盖嵌入式开发的日常调试需求，后续会单独介绍这些功能。
