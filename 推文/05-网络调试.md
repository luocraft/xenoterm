# XenoTerm — TCP/UDP 网络调试，客户端服务端都能开

调试网络通信协议，需要一个 TCP 客户端连设备？或者起一个 TCP 服务器等设备来连？又或者 UDP 广播测试？

XenoTerm 内置了网络调试工具，三种模式随意切换。

## TCP 客户端

填入 IP 和端口，一键连接。Hex 和文本双模式收发，适合调试 Modbus TCP、自定义 TCP 协议。

【截图：TCP 客户端连接和数据收发】

## TCP 服务器

本地起一个 TCP 服务器，等待设备连接。支持多客户端同时连接，可以选择向特定客户端或全部客户端发送数据。

【截图：TCP 服务器模式，显示已连接的客户端列表】

## UDP

支持 UDP 单播和广播，可指定本地绑定端口。适合调试 UDP 发现协议、组播通信。

【截图：UDP 收发界面】

## 通用功能

- 定时发送：设置间隔自动循环发送
- 数据录制：收发数据保存到文件
- 发送模板：预设常用指令一键发送

【截图：定时发送和发送模板】
