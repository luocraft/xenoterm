# XenoTerm — 嵌入式通用调试工作站，一个软件替代你桌面上的五六个工具

做嵌入式开发，桌面上是不是常年开着这些软件？

- SSH 终端（PuTTY / FinalShell）
- 文件传输（WinSCP / FileZilla）
- 串口调试（SSCOM / 友善串口）
- CAN 调试（CANTest / ZCANPRO）
- 网络调试（NetAssist / TCP 调试助手）

XenoTerm 把这些全整合到一个应用里了。

【截图：XenoTerm 主界面全貌，展示多个功能面板】

## 🖥️ SSH 终端 + SFTP

多标签分屏，跳板机，密钥认证，断线重连。SFTP 拖拽传输，右键操作，传输速度优化。

【截图：SSH 分屏 + SFTP 双栏】

## 🔧 CAN 总线

支持周立功、广成 USB CAN 设备（含 CAN FD）。DBC 信号解析，信号监控波形图，UDS 诊断，ASC/BLF 导出。

【截图：CAN 报文列表 + 信号波形图】

## ⚡ 串口调试

Hex/文本收发，DTR/RTS 控制，Modbus RTU 内置支持，寄存器轮询监控。

【截图：串口 + Modbus 寄存器监控】

## 🔌 网络调试

TCP 客户端/服务器、UDP，定时发送，数据录制。

【截图：TCP 服务器多客户端连接】

## 🔗 EtherCAT

从站扫描，SDO/PDO，FoE 固件升级，ESI 导入，SII 读写。

【截图：EtherCAT 从站列表和 SDO 面板】

## 为什么做这个

嵌入式开发的日常就是在各种调试工具之间切换，每个工具的 UI 风格不一样，数据也不互通。XenoTerm 的目标是提供一个统一的调试环境，减少工具切换的摩擦。

暗色主题护眼，中英文双语，界面紧凑不浪费空间。
