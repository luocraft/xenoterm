XenoTerm 帮助文档

XenoTerm — 通用调试工作站，集 SSH 终端、网络调试、串口调试、CAN 总线分析、EtherCAT 主站于一体。

🖥

多标签 · 分屏 · SFTP 文件传输 · 跳板机 · 命令历史 · 断线重连
🔌
网络调试
TCP Client / Server · UDP · HEX / UTF-8 · 发送模板 · 定时发送
⚡
串口调试
串口通信 · DTR/RTS · Modbus RTU · 寄存器监控 · 发送模板

从站扫描 · SDO/PDO · OD 浏览 · FoE 固件升级 · SII 读写

安装与启动

双击 XenoTerm Setup x.x.x.exe 安装程序，按照向导完成安装后即可从桌面或开始菜单启动。

也可以直接运行 release/win-unpacked/XenoTerm.exe 免安装使用。

连接管理

新建连接

  1. 点击左侧边栏的 + 新建连接 按钮
  2. 填写连接名称、主机地址、端口（默认 22）、用户名
  3. 选择认证方式（密码或公钥）
  4. 点击创建保存

连接到服务器

  • 双击左侧连接列表中的条目
  • 或右键点击 → 选择 连接
  • 如果使用密码认证且未保存密码，会弹出密码输入框

编辑 / 删除连接

右键点击连接条目，选择 编辑 或 删除。

断线重连

SSH 连接断开后，点击终端标签页上的重连按钮即可恢复会话。支持保存密码，重连时无需重新输入。

认证方式

密码认证

选择 密码 认证方式。可以在连接配置中预填密码，也可以留空在连接时输入。

公钥认证

选择 公钥 认证方式，并指定私钥文件路径（如 ~/.ssh/id_rsa）。如果私钥有密码保护，可以填写密钥密码 (Passphrase)。

终端操作

连接成功后会自动打开一个终端标签页，支持完整的 xterm-256color 终端模拟。

  • 选中文本自动复制到剪贴板
  • 右键点击终端区域自动粘贴
  • Ctrl+Shift+C 复制，Ctrl+Shift+V 粘贴
  • 终端字体、字号、配色方案可在终端设置中自定义
  • 点击标签页上的 ✕ 关闭终端并断开连接

工作区与分屏

支持将多个终端会话组合到一个工作区中，实现分屏显示。

创建分屏

将一个标签页拖拽到另一个标签页上，根据鼠标放置位置决定分屏方向：

  • 拖到左侧 / 右侧 → 左右水平分屏
  • 拖到上方 / 下方 → 上下垂直分屏
  • 拖到中央 → 替换当前窗格的会话

调整分屏比例

拖动分屏之间的分隔线即可调整比例，范围限制在 20%~80% 之间。

文件传输 (SFTP)

连接到服务器后，点击标签栏上的文件浏览器按钮打开 SFTP 面板。左侧为本地文件，右侧为远端文件。

上传与下载

  • 从本地面板拖拽文件到远端面板即可上传
  • 从远端面板拖拽文件到本地面板即可下载
  • 支持从操作系统桌面或文件夹直接拖拽文件到远端面板上传
  • 传输使用并发分块加速（25 路并发，128KB 分块），大文件传输速度快

传输进度

  • 传输进度实时显示在右下角浮窗中，包含文件名、进度条、传输速度
  • 传输完成后自动刷新对应目录的文件列表
  • 完成的传输记录 1 秒后自动消失
  • 支持取消正在进行的传输

路径导航

  • 点击路径栏可以直接编辑路径，按回车跳转
  • 远端路径输入时，以 / 结尾会自动预览目标目录内容
  • 点击 ↑ 按钮返回上级目录
  • 点击列头（名称/大小/修改时间）可以排序文件列表

文件右键操作

远端文件右键菜单

  • 重命名 — 弹出对话框修改文件或文件夹名称
  • 修改权限 — 输入八进制权限值（如 755、644）修改文件权限
  • 删除 — 删除文件或文件夹（文件夹会递归删除）

右键点击远端面板空白区域：

  • 新建文件夹 — 在当前目录创建新文件夹
  • 刷新 — 刷新当前目录文件列表

本地文件右键菜单

  • 在资源管理器中打开 — 在 Windows 资源管理器中定位到该文件
  • 复制路径 — 将文件完整路径复制到剪贴板

跳板机

如果目标服务器需要通过跳板机访问，可以在连接配置中指定跳板机。

  1. 先在连接列表中创建跳板机的连接配置
  2. 编辑目标服务器的连接配置，在 跳板机 字段中选择跳板机
  3. 连接时会自动先连接跳板机，再通过端口转发连接到目标服务器

导入 / 导出

点击侧边栏底部工具栏的导入导出按钮打开对话框。

  • 导出：将所有连接配置导出为 JSON，方便备份或迁移到其他电脑
  • 导入：从 JSON 文件导入连接配置，支持批量导入

网络调试助手

内置网络调试助手，支持 TCP 和 UDP 协议的数据收发测试。点击侧边栏底部工具栏的 🔌 按钮打开。

支持的模式

模式说明典型用途
TCP Client连接到远程 TCP 服务器测试服务端接口、协议调试
TCP Server监听本地端口，接受客户端连接模拟服务端、测试客户端设备
UDPUDP 数据报收发设备通信、广播测试

TCP Client

  1. 点击 + 新建，选择 TCP 客户端
  2. 输入目标服务器的 IP 地址和端口号
  3. 点击 连接 建立连接
  4. 在底部输入框输入数据并发送

TCP Server

  1. 点击 + 新建，选择 TCP 服务器
  2. 输入监听地址（0.0.0.0 监听所有网卡）和端口号
  3. 点击 开始监听
  4. 当有客户端连接时，状态栏显示连接数
  5. 可以选择向特定客户端或所有客户端广播发送数据

UDP

  1. 点击 + 新建，选择 UDP
  2. 输入目标 IP 和端口
  3. 可选填写本地绑定端口（留空则自动分配）
  4. 点击 连接 创建 UDP socket

编码与显示

  • UTF-8：以文本形式收发，适合文本协议
  • HEX：以十六进制形式收发，适合二进制协议
💡 发送 HEX 数据时，输入十六进制字符串即可，例如 48656C6C6F 等同于文本 Hello。

发送模板

预定义多条常用指令，支持命名、编码选择、一键发送和定时循环发送。

  • 点击 + 添加 创建发送模板
  • 每条模板可设置名称、数据内容、编码格式（HEX/UTF-8）
  • 支持单次发送和定时发送（设置间隔毫秒数）
  • 支持收起/展开模板面板

串口调试助手

内置串口调试助手，支持串口通信、Modbus RTU、发送模板等功能。点击侧边栏底部工具栏的 ⚡ 按钮打开。

打开串口

  1. 点击 + 新建，系统自动扫描可用串口
  2. 从下拉列表中选择串口（如 COM3），点击 ↻ 刷新列表
  3. 配置通信参数
  4. 点击 打开端口

串口配置

参数可选值默认值
波特率300 ~ 921600115200
数据位5, 6, 7, 88
停止位1, 1.5, 21
校验位无, 偶校验, 奇校验无
流控无, RTS/CTS, XON/XOFF无

控制信号

串口打开后，可以通过顶部按钮控制 DTR 和 RTS 信号线状态：

  • DTR (Data Terminal Ready)：某些开发板（如 ESP32）使用 DTR 触发复位
  • RTS (Request To Send)：某些开发板使用 RTS 进入下载模式

Modbus RTU

切换到 Modbus RTU 模式后，可以直接进行 Modbus 寄存器读写操作。

  • 选择功能码（FC01~FC06、FC15、FC16 等）
  • 填写从站地址、寄存器起始地址、数量/值
  • 点击发送，自动计算 CRC 校验
  • 响应数据自动解析显示

寄存器监控

设置轮询间隔后，自动周期性读取寄存器并以表格形式显示：

  • 显示寄存器地址、十进制值、十六进制值
  • 数据实时刷新，变化一目了然
  • 支持启动/停止轮询

发送模板（串口）

与网络调试的发送模板功能一致，支持预定义多条指令、命名、HEX/UTF-8 编码、单次发送和定时循环发送。

CAN 总线调试

内置 CAN 总线调试工具，支持 CAN 2.0 和 CAN FD，DBC 信号解析，J1939 协议，UDS 诊断，信号监控图表等。点击侧边栏底部工具栏的 🚗 按钮打开。

支持的硬件

驱动说明CAN FD双通道
ZLG（周立功）USBCAN-II 等设备—✅
GC（广成科技）USBCAN-II 设备—✅
GC-FD（广成 CAN FD）USBCANFD 设备✅✅
Virtual（虚拟设备）无需硬件，自动生成模拟报文——

连接与配置

  1. 选择 CAN 驱动
  2. 选择设备类型和通道号
  3. 设置仲裁域波特率（常用：250kbps、500kbps、1Mbps）
  4. 点击 连接 打开 CAN 通道

双通道设备（ZLG、GC、GC-FD）打开时会自动初始化两个通道，每个通道可独立配置波特率。

💡 选择 Virtual 驱动可以在没有硬件的情况下体验全部 CAN 调试功能。

CAN FD 支持

选择 GC-FD 驱动后，可以配置 CAN FD 相关参数：

  • 数据域波特率：CAN FD 数据段的波特率（如 2Mbps、5Mbps）
  • 支持发送 CAN FD 帧（DLC 最大 64 字节）
  • 两个通道可分别配置不同的仲裁域和数据域波特率

DBC 文件解析

支持导入 DBC（Database CAN）文件，自动解析报文和信号定义。

  • 点击 📂 导入 DBC 按钮选择文件
  • 导入后，接收到的报文自动解析并显示信号名称和物理值
  • 支持 factor、offset、min/max、unit 等信号属性
  • 支持 Intel（小端）和 Motorola（大端）字节序
  • 支持更换或卸载 DBC 文件

J1939 协议

对于 29 位扩展帧，自动按 J1939 协议解析 PGN（Parameter Group Number）：

  • 从 CAN ID 中提取优先级、PGN、源地址
  • 如果已加载 J1939 DBC 文件，自动匹配 PGN 并解析信号
  • J1939 消息在报文列表中单独显示 PGN 信息

报文监控

CAN 通道打开后，接收到的报文实时显示在消息列表中：

  • 显示时间戳、方向（TX/RX）、CAN ID、DLC、数据字节
  • 发送的报文也会显示在列表中，标记为 TX
  • 支持按方向过滤（全部 / 发送 / 接收）
  • 总线负载实时统计显示
  • 右键报文可快速填入发送栏或添加到信号监控

信号监控与图表

选中 DBC 信号后可添加到信号监控面板，提供三种视图：

仪表盘视图

以仪表盘形式显示信号当前值，直观查看信号状态。

波形图视图

  • 实时绘制信号变化曲线，支持多信号叠加显示
  • 支持暂停/继续、复位视图
  • 鼠标滚轮缩放，拖拽平移
  • Y 轴自动适应信号范围
  • 支持导出 CSV 数据

表格视图

以表格形式显示所有监控信号的当前值、最小值、最大值、单位。支持滑块控件直接修改信号值用于发送。

报文发送

手动发送

在发送栏输入 CAN ID 和数据字节，点击发送。支持标准帧和扩展帧，支持 CAN FD 帧。

发送列表

  • 点击 + 添加 创建发送项，设置 CAN ID、DLC、数据
  • 支持单次发送和定时循环发送（设置间隔毫秒数）
  • 如果已加载 DBC，可以按信号编辑数据内容
  • 支持删除发送项

ASC 录制与回放

  • ⏺ 录制 ASC：将收发的报文录制为 ASC 格式日志文件
  • ▶ 回放 ASC：导入 ASC 文件，按时间戳回放报文

UDS 诊断

内置 UDS（Unified Diagnostic Services，ISO 14229）诊断面板，支持常用诊断服务。

基本配置

  • 请求 ID (TxID)：诊断请求的 CAN ID（如 0x7DF 或 0x741）
  • 响应 ID (RxID)：诊断响应的 CAN ID（如 0x7E8 或 0x749）

支持的服务

服务SID说明
会话控制0x10切换默认/编程/扩展会话
ECU 复位0x11硬复位/软复位/KeyOff-On
安全访问0x27请求种子、发送密钥
读 DID0x22读取数据标识符
写 DID0x2E写入数据标识符
清除 DTC0x14清除诊断故障码
读取 DTC0x19读取诊断故障码
IO 控制0x2F输入输出控制
例程控制0x31启动/停止/查询例程
原始数据自定义直接发送 Hex 数据

TesterPresent 心跳

点击 ▶ 启动心跳 后，自动周期性发送 TesterPresent (0x3E) 请求，保持诊断会话不超时。

ISO-TP 分包

UDS 请求和响应自动通过 ISO-TP（ISO 15765-2）协议进行分包和重组，支持多帧传输，无需手动处理。

通信日志

所有 UDS 请求和响应记录在日志表格中，显示序号、方向、SID、服务名、数据、结果（正响应/负响应及 NRC 码）。

数据导出

  • 📥 导出 CSV：将信号监控数据导出为 CSV 文件
  • 📦 导出 BLF：将 CAN 报文导出为 BLF（Binary Logging Format）文件，可用 Vector CANalyzer 等工具打开
  • ⏺ 录制 ASC：实时录制为 ASC 格式日志

EtherCAT 主站

内置 EtherCAT 主站功能（基于 SOEM），支持从站扫描、状态管理、SDO/PDO 通信、OD 浏览、FoE 固件升级、SII 读写等。点击侧边栏底部工具栏的 ⚙️ 按钮打开。

💡 EtherCAT 功能依赖 WinPcap 或 Npcap 网络驱动。如果没有安装硬件驱动，可以选择 Virtual 模式体验功能。

连接与扫描

  1. 从网络适配器列表中选择连接 EtherCAT 从站的网卡
  2. 点击 🔗 连接 初始化主站并扫描从站
  3. 扫描完成后，左侧显示从站列表（名称、状态、厂商信息）
  4. 点击从站查看详细信息

状态管理

状态说明
INIT初始化状态，从站刚上电或复位后
PRE-OP预操作状态，可进行 SDO 通信和邮箱配置
SAFE-OP安全操作状态，PDO 输入有效但输出无效
OP操作状态，PDO 输入输出均有效

可以通过状态切换按钮请求从站进入指定状态。状态切换失败时会显示 AL Status Code 及中文说明。

错误计数器

显示每个从站的 Invalid Frame、RX Error、Lost Link 计数，支持一键清零。

SDO 读写

SDO（Service Data Object）用于访问从站的对象字典。

  • 输入 Index（对象索引）和 SubIndex（子索引）
  • 选择数据类型（UINT8、INT16、UINT32 等）
  • 点击 📖 读取 或 ✏️ 写入

OD 浏览器

  • 点击 Scan OD 扫描从站完整对象字典
  • 支持导入 ESI（EtherCAT Slave Information）XML 文件，获取对象名称和描述

PDO 映射

PDO（Process Data Object）用于实时周期性数据交换。

  • 点击 ▶ 启动 PDO 开始周期性数据交换
  • 输入 PDO 数据实时显示，输出 PDO 可手动修改并写入
  • 点击 📡 解析信号 将 PDO 数据解析为具名信号（需要 ESI 文件）
  • 支持信号实时波形图绘制

FoE 固件升级

FoE（File over EtherCAT）用于向从站上传固件文件。

  1. 确保从站处于 PRE-OP 或 INIT 状态
  2. 选择固件文件
  3. 输入文件名和密码（如果需要）
  4. 点击 Upload 开始上传，进度条显示传输进度

SII 读写

SII（Slave Information Interface）用于读写从站 EEPROM 中的身份信息。

  • 输入偏移地址和读取长度，点击读取
  • 支持写入 SII 数据（谨慎操作，错误写入可能导致从站无法识别）

主题切换

XenoTerm 支持深色和浅色两种主题。点击侧边栏底部工具栏的主题切换按钮即可切换。

  • 深色主题（默认）：适合长时间使用，减少眼睛疲劳
  • 浅色主题：适合明亮环境下使用
  • 主题设置会自动保存，下次启动时恢复

许可证

XenoTerm 需要有效的许可证才能使用全部功能。

  • 点击侧边栏底部工具栏的许可证按钮打开激活对话框
  • 输入许可证密钥并点击激活
  • 激活成功后显示许可证状态和到期时间
  • 许可证绑定当前设备，不可在多台设备上同时使用

常见问题

SSH 连接失败怎么办？

  • 检查目标服务器的 IP 地址和端口是否正确
  • 确认目标服务器的 SSH 服务已启动
  • 检查防火墙是否放行了 SSH 端口
  • 如果使用公钥认证，确认私钥文件路径正确且格式有效
  • 如果使用跳板机，确认跳板机连接配置正确

SFTP 传输速度慢？

  • XenoTerm 默认使用 25 路并发 + 128KB 分块加速传输
  • 如果速度仍然较慢，可能是网络带宽限制或服务器端限速
  • 检查是否通过跳板机连接，跳板机可能成为瓶颈

CAN 设备连接不上？

  • 确认 CAN 适配器已正确连接到电脑 USB 端口
  • 确认选择了正确的驱动类型（ZLG / GC / GC-FD）
  • 检查设备管理器中是否识别到 CAN 适配器
  • 确认 CAN 总线波特率与目标设备一致
  • 检查 CAN 总线终端电阻是否正确（120Ω）

CAN FD 帧收发异常？

  • 确认使用 GC-FD 驱动，其他驱动不支持 CAN FD
  • 确认仲裁域和数据域波特率配置正确
  • 确认对端设备也支持并启用了 CAN FD

EtherCAT 扫描不到从站？

  • 确认已安装 WinPcap 或 Npcap 网络驱动
  • 确认选择了正确的网络适配器（连接从站的那个网卡）
  • 检查网线连接是否正常
  • 尝试以管理员权限运行 XenoTerm

串口打不开？

  • 确认串口设备已连接并在设备管理器中显示
  • 确认串口没有被其他程序占用
  • 点击刷新按钮重新扫描可用串口
  • 尝试拔插 USB 转串口设备后重试

如何导出 CAN 数据用于分析？

  • BLF 格式：可用 Vector CANalyzer、CANoe 等工具打开分析
  • CSV 格式：可用 Excel 或 Python 脚本进行数据处理
  • ASC 格式：通用 CAN 日志格式，兼容大多数 CAN 分析工具
