XenoTerm 帮助文档

XenoTerm 是一款集 SSH 终端管理与网络调试于一体的桌面工具，基于 Electron 构建。

功能一览

  • SSH 远程连接管理，支持密码和公钥认证
  • 多标签页 + 工作区分屏，支持拖拽排列
  • SFTP 文件浏览与上传下载
  • 跳板机 (Jump Host) 支持
  • 连接配置导入 / 导出
  • 命令历史记录
  • 网络调试助手：TCP Client / TCP Server / UDP 数据收发
  • 串口调试助手：串口通信、DTR/RTS 控制信号
  • 深色 / 浅色主题切换

安装与启动

双击 XenoTerm Setup 1.0.0.exe 安装程序，按照向导完成安装后即可从桌面或开始菜单启动。

也可以直接运行 release/win-unpacked/XenoTerm.exe 免安装使用。

连接管理

新建连接

  1. 点击左侧边栏的 + New 按钮
  2. 填写连接名称、主机地址、端口（默认 22）、用户名
  3. 选择认证方式（密码或公钥）
  4. 点击保存

连接到服务器

  • 双击左侧连接列表中的条目
  • 或右键点击 → 选择 Connect
  • 如果使用密码认证，会弹出密码输入框

编辑 / 删除连接

右键点击连接条目，选择 Edit 编辑或 Delete 删除。

认证方式

密码认证

选择 Password 认证方式。连接时会弹出密码输入框，密码不会被保存到配置文件中。

公钥认证

选择 Public Key 认证方式，并指定私钥文件路径（如 ~/.ssh/id_rsa）。如果私钥有密码保护，可以填写 Passphrase。

终端操作

连接成功后会自动打开一个终端标签页，支持完整的 xterm-256color 终端模拟。

  • 终端支持鼠标选择、复制粘贴
  • 输入的命令会自动记录到命令历史中
  • 点击标签页上的 ✕ 按钮关闭终端并断开连接

工作区与分屏

XenoTerm 支持将多个终端会话组合到一个工作区中，实现分屏显示。

创建工作区

将一个标签页拖拽到另一个标签页上，会自动创建工作区并分屏显示。

分屏方向

拖拽时，根据鼠标放置的位置决定分屏方向：

  • 拖到左侧 → 左右水平分屏（新窗格在左）
  • 拖到右侧 → 左右水平分屏（新窗格在右）
  • 拖到上方 → 上下垂直分屏（新窗格在上）
  • 拖到下方 → 上下垂直分屏（新窗格在下）
  • 拖到中央 → 替换当前窗格的会话

调整分屏比例

拖动分屏之间的分隔线即可调整比例，范围限制在 20%~80% 之间。

从工作区移除

在工作区内关闭某个终端的标签页，该窗格会被移除，布局自动调整。当工作区只剩一个会话时，工作区自动解散。

文件传输 (SFTP)

连接到服务器后，可以通过文件管理器进行远程文件浏览和传输。

  • 支持远程目录浏览
  • 支持文件上传和下载
  • 传输进度实时显示在底部传输队列中
  • 支持取消正在进行的传输

跳板机

如果目标服务器需要通过跳板机访问，可以在连接配置中指定 Jump Host。

  1. 先在连接列表中创建跳板机的连接配置
  2. 编辑目标服务器的连接配置，在 Jump Host 字段中选择跳板机
  3. 连接时会自动先连接跳板机，再通过端口转发连接到目标服务器

导入 / 导出

点击侧边栏的 ⇄ 按钮打开导入导出对话框。

  • 导出：将所有连接配置导出为 JSON 文件，方便备份或迁移
  • 导入：从 JSON 文件导入连接配置，支持批量导入，无效条目会给出错误提示

网络调试助手

XenoTerm 内置了网络调试助手，支持 TCP 和 UDP 协议的数据收发测试，适用于嵌入式开发、协议调试、服务端测试等场景。

点击侧边栏的 🔌 按钮打开网络调试面板。

支持的模式

模式 说明 典型用途
TCP Client 连接到远程 TCP 服务器 测试服务端接口、协议调试
TCP Server 监听本地端口，接受客户端连接 模拟服务端、测试客户端设备
UDP UDP 数据报收发 嵌入式设备通信、广播测试

TCP Client

  1. 点击 + New，选择 TCP Client
  2. 输入目标服务器的 IP 地址和端口号
  3. 点击 Connect 建立连接
  4. 连接成功后，在底部输入框输入数据并点击 Send 发送
  5. 接收到的数据会实时显示在消息列表中

TCP Server

  1. 点击 + New，选择 TCP Server
  2. 输入监听地址（默认 127.0.0.1，填 0.0.0.0 监听所有网卡）和端口号
  3. 点击 Start Listening 开始监听
  4. 当有客户端连接时，状态栏会显示连接数
  5. 可以选择向特定客户端或所有客户端广播发送数据

UDP

  1. 点击 + New，选择 UDP
  2. 输入目标 IP 和端口（发送目标）
  3. 可选填写本地绑定端口（用于接收数据，留空则自动分配）
  4. 点击 Connect 创建 UDP socket
  5. 发送数据会以 UDP 数据报形式发送到目标地址
  6. 如果绑定了本地端口，可以接收其他设备发来的数据

编码与显示

网络调试助手支持两种数据编码模式：

  • UTF-8：以文本形式发送和显示数据，适合文本协议（如 HTTP、MQTT 等）
  • HEX：以十六进制形式发送和显示数据，适合二进制协议

发送 HEX 数据

切换发送编码为 HEX 后，在输入框中输入十六进制字符串，例如：

48656C6C6F

等同于发送文本 Hello。

切换显示编码

消息列表顶部的编码选择器可以随时切换显示模式，在 UTF-8 和 HEX 之间切换查看同一份数据。

串口调试助手

XenoTerm 内置串口调试助手，支持常见的串口通信参数配置和数据收发，适用于嵌入式开发、单片机调试、设备通信等场景。

点击侧边栏底部工具栏的 🔗 Serial 按钮打开串口调试面板。

打开串口

  1. 点击 + New，系统会自动扫描可用串口
  2. 从下拉列表中选择串口（如 COM3），点击 ↻ 可刷新列表
  3. 配置通信参数（波特率、数据位、停止位、校验位、流控）
  4. 点击 Open Port 打开串口
  5. 在底部输入框输入数据并点击 Send 发送

串口配置

参数 可选值 默认值
波特率 (Baud Rate) 300 ~ 921600 115200
数据位 (Data Bits) 5, 6, 7, 8 8
停止位 (Stop Bits) 1, 1.5, 2 1
校验位 (Parity) None, Even, Odd None
流控 (Flow Control) None, RTS/CTS, XON/XOFF None

控制信号

串口打开后，可以通过顶部的 DTR 和 RTS 按钮控制信号线状态：

  • DTR (Data Terminal Ready)：数据终端就绪信号，常用于通知设备主机已准备好通信。某些开发板（如 ESP32）使用 DTR 信号触发复位。
  • RTS (Request To Send)：请求发送信号，用于硬件流控或设备控制。某些开发板使用 RTS 信号进入下载模式。

点击按钮可以切换 ON/OFF 状态，绿色表示高电平（ON），灰色表示低电平（OFF）。

主题切换

点击侧边栏顶部的 ☀️ / 🌙 按钮可以在深色和浅色主题之间切换。主题设置会自动保存。

常见问题

连接超时怎么办？

  • 检查目标服务器的 IP 地址和端口是否正确
  • 确认网络连通性（可以先 ping 一下目标地址）
  • 检查防火墙是否放行了对应端口
  • 如果使用跳板机，确认跳板机配置正确且可达

认证失败怎么办？

  • 密码认证：确认用户名和密码正确
  • 公钥认证：确认私钥文件路径正确，且对应的公钥已添加到服务器的 ~/.ssh/authorized_keys
  • 如果私钥有密码保护，确认 Passphrase 填写正确

TCP Server 监听失败？

  • 端口可能已被其他程序占用，换一个端口试试
  • 监听 0.0.0.0 时可能需要管理员权限（端口号 < 1024）

UDP 收不到数据？

  • 确认已填写本地绑定端口，且发送方的目标端口与之一致
  • 检查防火墙是否放行了 UDP 端口

配置文件在哪里？

配置文件保存在系统用户数据目录下：

%APPDATA%/xenoterm/ssh-client-config.json
